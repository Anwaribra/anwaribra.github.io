# Portfolio Image Update Instructions

## Akatsuki Cloud Logo Integration

To complete the Akatsuki cloud logo integration in your portfolio:

1. Save the `vecteezy_akatsuki-emblem-naruto-anime-naruto-red-cloud-art-isolated_29890086.jpg` file to:
   - `assets/images/akatsuki-cloud.png` (for the main logo)
   - `assets/favicons/favicon.png` (for the browser tab icon)

2. Make sure to:
   - Remove the background from the image if it has one
   - Resize it to fit properly in the circular logo container (approximately 52x52px)
   - Keep the red cloud visible and centered

The image files have been prepared at the correct locations, you just need to replace them with your Akatsuki cloud image.
